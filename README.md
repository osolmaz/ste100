# ste100

ste100 is an open-source checker for ASD-STE100 Simplified Technical English.
It will check vocabulary and grammar with deterministic rules.
It will also check terminology, document structure and document-level requirements.

The checker is under development.
The repository currently contains a searchable text copy of the standard for implementation and testing.
