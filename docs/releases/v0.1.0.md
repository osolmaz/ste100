# Deterministic checker v0.1.0

Version 0.1.0 used an incorrect result model. It presented internal review and coverage states as if they described ASD-STE100 outcomes. It also labeled the extracted data as reviewed without a complete manual audit.

Version 0.2.0 replaces that model. Do not use 0.1.0 results for compliance decisions.

The source rules, dictionary extraction, exact byte offsets, and deterministic checks were retained where they supported factual findings. The invented result states, coverage matrix, generated standard examples, and reviewed labels were removed.
