# Deterministic checker v0.1.0

This is the release record for the first deterministic `ste100` package. The release target is tag `v0.1.0` on the merged default branch.

## Standard data

- Source: ASD-STE100 Issue 9
- Source text SHA-256: `a216fe199bd6e9c77fc743dfe6dc081ee5f245adcb115ed6ca1aa45ee50fa3f5`
- Combined runtime-pack SHA-256: `a6a098d57bb1d6718bd4d48d9714f686192d08d0f33891f7e3b5e1b0e4d987e2`
- Rules and recommendations: 61
- Approved dictionary rows: 878
- Unapproved dictionary rows: 1,318
- Standard examples: 15

Issue 9 prints totals of 875 approved and 1,274 unapproved words. The runtime pack retains every repaired part-of-speech row found in the source table. Validation reports the difference as a warning. Every row has a unique status, headword, and part-of-speech key plus a source page and source digest.

## Coverage

- Full mechanical coverage: 7 requirements
- Partial mechanical coverage: 29 requirements
- Human review only: 25 requirements

A partial check cannot pass the complete requirement. The analysis output always includes all 61 coverage records.

## Package artifacts

The release attaches `ste100-0.1.0.tar.gz` and `ste100-0.1.0-py3-none-any.whl`. GitHub records the final asset digests.

The wheel contains the five runtime-pack JSON files. A clean Python 3.12 environment loaded the bundled pack, analyzed a file, explained Rule 8.1, and validated the installed pack without making a network system call during runtime.

## Checks

- Ruff lint and formatting passed.
- Strict mypy passed.
- 103 tests passed with 94.58% branch coverage.
- Pip-audit found no known vulnerabilities. The local package and official spaCy model are not indexed on PyPI and were reported as unaudited.
- The mutation gate killed 32 of 38 schema-generator mutants, for 84.21%, with no timeouts.
- Slophammer reported no findings and no duplicate-code candidates.
- SimpleDoc passed.
- The private response-style regression checked 550 records, 749 responses, and 199 revision pairs without printing private text.

## Optional spaCy checks

The optional checker uses spaCy 3.8.11 with `en_core_web_sm` 3.8.0. Manually verified tests cover imperative procedures, passive voice, notes, safety openings, listed verb forms, multiple actions, and cases that must remain in human review.

## Boundaries

The package does not certify official ASD-STE100 compliance. Contextual meaning, topic structure, ambiguity, and other non-mechanical requirements remain human-review work.
