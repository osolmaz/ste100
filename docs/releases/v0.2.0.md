# Source-backed results v0.2.0

Version 0.2.0 replaces the incorrect result model from 0.1.0. The checker now returns a binary tool result and only source-backed findings.

## Result changes

- `passed` is `true` when the implemented checks find no issue.
- Findings contain official rule IDs, a factual message, a UTF-8 byte range, and the exact excerpt.
- One source span produces one finding.
- Internal review and coverage fields are removed. Confidence and applicability fields are removed too. Checker fields and release gates are also removed.
- Unsupported and ambiguous checks emit nothing.
- General recommendations remain available through `ste100 explain` but do not produce findings.

This is a breaking change to the JSON and text output formats.

## Extracted data

The runtime package now contains only:

- `standard.json`
- `rules.json`
- `dictionary.json`

Generated examples, conformance records, reviewed labels, count reconciliation, and coverage claims are removed.
